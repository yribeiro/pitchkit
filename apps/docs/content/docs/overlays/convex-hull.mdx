## Usage

`<ConvexHull>` takes `x`/`y` accessors per datum (one point per datum, like `<Scatter>`) and
renders a single filled polygon around the outermost points.

```tsx
<ConvexHull data={touches} x={(t) => t.x} y={(t) => t.y} />
```
