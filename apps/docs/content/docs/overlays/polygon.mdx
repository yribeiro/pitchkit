## Usage

`<Polygon>` takes a `points` accessor per datum, returning that shape's vertices as
`[x, y]` pairs in provider coordinates. One datum draws one filled polygon.

```tsx
<VerticalPitch type="statsbomb" crop={cropForHalf(dimensions)}>
  <Polygon data={zones} points={(z) => z.vertices} />
</VerticalPitch>
```
