## Usage

`<Arrows>` takes `x`/`y` (start) and `x2`/`y2` (end) accessors per datum — good for pass maps
and set-piece routines.

```tsx
<Arrows data={passes} x={(p) => p.from.x} y={(p) => p.from.y} x2={(p) => p.to.x} y2={(p) => p.to.y} />
```
