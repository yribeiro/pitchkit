A pass map on a dark navy board, where successful passes stand out in teal and unsuccessful
ones sit back in pink. The data is Opta-style event rows: `typeId` 1 is a pass and `outcome`
is 1 or 0.

<PitchPreview name="styling-opta-basic" />

## The classes

| Element      | Classes                                                                                   |
| ------------ | ----------------------------------------------------------------------------------------- |
| Pitch        | `pitch-surface-slate-900 pitch-stripe-slate-800 pitch-lines-slate-500 pitch-line-width-1` |
| Successful   | `fill-teal-300 stroke-teal-300`                                                           |
| Unsuccessful | `fill-pink-400 stroke-pink-400 opacity-60`                                                |

`<Arrows>` needs both a `stroke-*` (the shaft) and a `fill-*` (the head). The unsuccessful
layer is declared first so the successful passes paint over it.

## Coordinates

Opta's grid is **percentages**: 0–100 on both axes, origin bottom-left, y pointing up.
`type="opta"` still draws a real 105:68 pitch rather than a square, so the percentages go in
unconverted. In a raw Opta feed a pass's end location is in qualifiers 140 (x) and 141 (y). The
sample lifts them to `endX`/`endY`.

<Callout type="warn">
  Wyscout is also 0–100 on both axes, but its y points **down**. Plotting Opta data on
  `type="wyscout"`, or the reverse, mirrors the chart vertically and nothing errors. See
  [Wyscout](/docs/styling/wyscout).
</Callout>

## With real data

Opta data is commercial and there's no open-data loader for it in `@pitchkit/data-providers`.
Parse your own feed into rows like the sample and the chart code doesn't change.
