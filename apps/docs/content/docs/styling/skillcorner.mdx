A single frame of broadcast tracking: 22 players and the ball, on a near-black pitch with
low-contrast markings so the dots carry the picture. The data is SkillCorner `player_data`
rows with their own field names (`player_id`, `is_detected`).

## The classes

| Element                   | Classes                                                                                |
| ------------------------- | -------------------------------------------------------------------------------------- |
| Pitch                     | `pitch-surface-zinc-950 pitch-stripe-zinc-900 pitch-lines-zinc-600 pitch-line-width-1` |
| Home, seen                | `fill-sky-400`                                                                         |
| Home, extrapolated        | `fill-transparent stroke-sky-400`                                                      |
| Away, seen / extrapolated | `fill-rose-500` / `fill-transparent stroke-rose-500`                                   |
| Ball                      | `fill-white stroke-zinc-950`                                                           |

Broadcast tracking only sees what the camera framed. A player with `is_detected: false` is an
**estimated** position, not a measured one, and drawing those as hollow rings keeps the chart
honest about it. Styling is how that distinction gets shown.

## Coordinates

`type="skillcorner"` uses SkillCorner's own grid: metres from the centre spot. Raw `x`/`y` go
straight in, with no offset or flip. Pitch sizes vary by stadium (104–106 × 68 m), so pass
the match's real size through `dimensions`. Tracking positions are absolute and swap ends at
half time. [Tracking](/docs/data/skillcorner/tracking) covers what that means for a
full match.

## With real data

[`@pitchkit/data-providers/skillcorner`](/docs/data/skillcorner/tracking) streams tracking
frames without downloading the whole ~90 MB file, and the match file gives each player a team
and the pitch its real size:

```tsx
import { fetchMatch, streamTracking } from "@pitchkit/data-providers/skillcorner";

const match = await fetchMatch(matchId);
for await (const frame of streamTracking(match)) {
  // frame.player_data, frame.ball_data — same shape as the sample
  break; // leaving the loop aborts the download
}
// <Pitch type="skillcorner" dimensions={{ length: match.pitch_length, width: match.pitch_width }}>
```
