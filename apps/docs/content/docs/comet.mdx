## Usage

Like `<Arrows>`, `<Comet>` takes start (`x`/`y`) and end (`x2`/`y2`) accessors, plus
`startWidth`/`endWidth` to control the taper and `gradient` to fade opacity along its length.

```tsx
<Comet data={carries} x={(c) => c.from.x} y={(c) => c.from.y} x2={(c) => c.to.x} y2={(c) => c.to.y} gradient />
```
